# ImLagGoGoGo: CS2 死后全自动狡辩工具 (Go 重构实施规划 v2)

## 1. 项目愿景与设计哲学

基于前面对原版 `ImLag`（C# 2.0.6 控制台 / 3.0.0 Godot GUI）的逆向与调研，本项目 `ImLagGoGoGo` 旨在用 **Go 1.24** 打造一个极致轻量、超低内存开销、架构清晰且具备跨平台潜力的现代化替代品。

### 核心指标
- **超低常驻内存**：运行时内存控制在 **8MB ~ 15MB**，对 CS2 竞技帧率完全零干扰。
- **纯静态单文件**：零外部依赖、无需安装 .NET 运行时或 VC++ 运行库，双击即跑。
- **模块与视觉设计**：驱动层物理拆分 `windows` 与 `linux` 独立目录，与 VSCode Material Icon Theme 完美契合，兼顾代码美感与架构扩展性。

## 3. 驱动工厂与接口设计

### 3.1 抽象契约 (`internal/driver/driver.go`)
```go
package driver

// Driver 定义跨平台操作系统的底层适配契约
type Driver interface {
    WindowTracker
    InputInjector
    CfgLocator
}

// WindowTracker 负责检测 CS2 游戏是否处于当前前台活动状态
type WindowTracker interface {
    IsCS2Foreground() bool
}

// InputInjector 负责向游戏窗口模拟聊天按键和发送中文字符串
type InputInjector interface {
    SendChatMessage(chatKey string, message string, delayMs int) error
}

// CfgLocator 负责检测 Steam/CS2 路径并自动安装 GSI 配置文件
type CfgLocator interface {
    LocateCS2Path() (string, error)
    InstallGSIConfig(listenPort int) error
    WriteSelectorCfg(messages []string, bindKeys []string) error
}
```

### 3.2 编译期无缝绑定工厂

## 4. 关键实现亮点 (Windows 端)

1. **中文直输防候选框吞字 (`internal/driver/windows/injector.go`)**：
   - 传统模拟器（如 `keybd_event`）发送的是虚拟键码，会激活搜狗/微软拼音输入法的汉字候选框，导致打出的文字变成拼音字母并卡在公屏；
   - 本方案采用 Windows API `SendInput` 并指定 `KEYEVENTF_UNICODE`（`0x0004`），直接将 UTF-16 字符码点压入游戏输入缓冲区，彻底免疫输入法候选框干扰。
2. **切屏安全保障 (`internal/driver/windows/tracker.go`)**：
   - 每次死亡触发时，毫秒级调用 `GetForegroundWindow`，通过 PID 严格核验是否为 `cs2.exe`；
   - 若玩家切出去看视频、聊天或在桌面，自动放弃发送，防止借口被误发到办公软件或浏览器中。
3. **Steam 库全盘自动寻路 (`internal/driver/windows/locator.go`)**：
   - 读取注册表 `HKCU\Software\Valve\Steam\SteamPath`；
   - 自动解析 `libraryfolders.vdf`，即使 CS2 安装在 D 盘、E 盘或移动硬盘，也能自动精确定位并部署 GSI 配置。
